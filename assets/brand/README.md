# Arquivos da marca

Versões vetoriais reconstruídas a partir da logo oficial (avatar do Instagram e capa do LinkedIn).

| Arquivo | Uso |
|---|---|
| `roki-logo.svg` / `.png` | Logo horizontal, texto vermelho, fundo transparente (para fundos claros) |
| `roki-logo-negativo.svg` / `.png` | Logo horizontal, texto creme, fundo transparente (para fundos escuros ou vermelhos) |
| `roki-simbolo.svg` / `.png` | Só o símbolo (círculo, ロキ e monte), fundo transparente, 2048 px |
| `favicon.svg` | Ícone do navegador |

Prefira sempre o SVG: ele não perde qualidade em nenhum tamanho. Os PNGs têm alta resolução
(logo com 3000 px de largura, símbolo com 2048 px).

## Observações

- O símbolo foi redesenhado com geometria limpa sobre as medidas da logo original.
- O texto "ROKI CONTABILIDADE" foi convertido em curvas usando a fonte **Outfit** (Google Fonts, licença OFL),
  a mais próxima da original. Se quem criou a logo informar a fonte exata, dá para regerar os arquivos.
