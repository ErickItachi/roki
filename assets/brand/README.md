# Arquivos da marca

Coloque aqui os arquivos oficiais enviados pela Roki:

- `logo.svg` — logotipo principal (versão para fundo claro)
- `logo-white.svg` — versão para fundo escuro
- `favicon.svg` — símbolo/ícone (substitui o provisório)

Depois, troque o bloco `.brand` em `index.html` pela tag `<img>` indicada no comentário.
